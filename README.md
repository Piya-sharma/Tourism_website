
# Tourism Website

A tourism website project developed using HTML and CSS to present travel destinations through a simple and user-friendly website interface.

## Project Overview

This project demonstrates my front-end web development skills, including creating web pages, structuring content with HTML, and styling page layouts using CSS.

## Technologies Used

- HTML5
- CSS3

## Features

- Tourism-related web pages
- Travel destination information
- Images and visual content
- Navigation between website pages

## Project Structure

The repository contains HTML pages, styling files, and image assets required for the website.

## Live Demo

https://piya-sharma.github.io/Tourism_website/

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Purpose

This project was created to practise front-end web development and build a practical website project for my portfolio.
